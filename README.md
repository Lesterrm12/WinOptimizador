# ⚡ WinOptimizador Pro

**WinOptimizador** es una utilidad de sistema moderna, ligera y de código abierto desarrollada en **C# (Windows Forms)** y **PowerShell** para optimizar, limpiar y exprimir al máximo el rendimiento en equipos con Windows.

Diseñado con una interfaz moderna en modo oscuro, tarjetas responsivas y un sistema modular basado en un archivo de configuración externo (`servicios.txt`).

---

## 🛠️ Características Principales

* **📦 Panel de Servicios de Windows:** Permite auditar y desactivar de forma segura servicios innecesarios (telemetría, Xbox Live, mapas, etc.) para liberar memoria y recursos. Cuenta con contadores en tiempo real y funciones de marcado masivo.
* **🧹 Limpieza Flash:** Elimina de manera silenciosa los archivos temporales de usuario, la caché de Windows y vacía el DNS.
* **⚡ Máximo Rendimiento:** Desbloquea y activa el plan de energía oculto de alto rendimiento de Windows mediante comandos nativos elevados.
* **🛡️ Optimización de Windows Defender:** Limita el consumo de CPU del antivirus al 20% durante análisis en segundo plano para evitar tirones al jugar o trabajar.
* **🛠️ Caja de Herramientas Avanzada:** Accesos directos rápidos y organizados a utilidades nativas del sistema (`dxdiag`, `cleanmgr`, `mrt`, `msconfig`, `gpedit.msc`, `netplwiz`).

---

## 🚀 Requisitos y Ejecución

1. Asegúrate de tener el entorno de ejecución de Windows (.NET Framework).
2. Coloca en la misma carpeta el archivo ejecutable junto con **`icono.ico`** y **`servicios.txt`**.
3. Ejecuta la aplicación **como Administrador** (es indispensable para aplicar los cambios de PowerShell en los servicios del sistema).
